## Problem Overview
Level 1 (the idiot test)

This level is what we call "The Idiot Test", if you can't complete it, don't give up on learning all you can, but, don't go begging to someone else for the answer, thats one way to get you hated/made fun of. Enter the password and you can continue.

## Solution
In this challenge we are asked to input a password. But, there is a clue on it: they told us a lot about HTML! So we might want to check the source code by inspecting it (Ctrl + Shift + C). On the elements tab, analyze it properly and we will get the password `8c315b46`
